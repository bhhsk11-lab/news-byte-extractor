# NEWS BYTE Source Extractor 1.12.0

Google News is resolved before extraction. Server Chromium is the last-resort resolver with a 20-second Chromium-only resolution budget. Playwright navigation timeout remains 0; the resolver code controls the 20-second budget so redirect and DOM inspection can run continuously without a shorter Playwright navigation cutoff. If no publisher URL is resolved, `/extract` returns `resolved_url: null` and the raw Google URL must not be forwarded to the secondary/auth-bypass extractor. If a publisher URL is resolved but primary extraction is empty/low-quality, the real publisher URL is preserved so the extension can send only that URL to the secondary extractor.
